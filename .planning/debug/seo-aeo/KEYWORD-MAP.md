## 2. Cannibalization Guard Rules

1. **No Shared Primary Keywords:** Every public page possesses a distinct Primary Keyword.
2. **Clear Hierarchical Roles:**
   - Homepage (`/`): High-level entity overview + direct call-to-action.
   - Capability Landing Pages (`/handwritten-*`, `/text-to-handwriting`): Targeted to specific functional intents with tailored live interactive previews.
   - Knowledge Hub (`/learn/*`): In-depth informational answers answering "how to", linking back to capability tools.
3. **Internal Anchor Text Discipline:** Internal links use natural, descriptive anchor text aligned with the destination page's Primary Keyword.
